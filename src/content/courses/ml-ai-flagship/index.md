Welcome to the **ML/AI Flagship Course**!

This workshop series builds up your intuition for **neural networks**. We start with small models you can see on one graph, but every idea you meet is also used to train large neural networks.

**How to use this course**

Find each workshop in the sidebar, or click **Next** to work through them in order. Each workshop has three parts:

- **Slides** introduce the ideas. They are linked at the top of each workshop.
- **A Google Colab notebook** is where you write and run your own code. Save your own copy before you start.
- **The workshop page on this website** is a copy of the Colab notebook with the answers included. Try each exercise in Colab before you open its answer here.
